# 日频价格口径与历史 ST 修复

## 变更

- 后复权 OHLC 保留用于涨幅、均线、收益和回测，另补 `raw_open/high/low/close` 未复权价格。
- VWAP 偏离改为 `raw_close / (amount / volume) - 1`。缺少同口径价格或成交量、成交额无效时保留空值。因子版本更新为 `factor_v005`，使旧计算检查点失效。
- `adj_factor` 为同一股票、同一交易日的复权收盘价 / 未复权收盘价；缺少价格时为空，不再硬填 1。
- `st_flag` 来自 BaoStock 逐日 `isST`，明确区分 ST、非 ST 和未知；记录字段来源。当前股票名称不用于倒推历史状态。
- 日常 BaoStock 采集同时查询后复权和未复权历史；AkShare 回退也补未复权价格，无法确认 ST 时保留未知，并保留重叠日期此前已核实的 ST 状态。
- 条件筛选和策略实验不再把未知 ST 当作非 ST。实验页展示历史和调仓信号日的状态覆盖率；导出结果保留覆盖统计，实验引擎版本为 `daily-strategy-lab-v2`。

字段定义核对来源：[BaoStock Python API 文档](https://baostock.com/mainContent?file=pythonAPI.md)。未复权查询使用 `adjustflag=3`；成交量单位为股、成交额单位为元；每日 `isST` 为 1/0。

## 补数与恢复

`python scripts/backfill_daily_price_status.py --publish` 按股票缓存历史响应，校验每个既有日期的原始 OHLC、成交量、成交额及 ST 状态。全量通过后先备份原文件，再原子替换；缺行、重复日期、无效状态或成交量单位不一致均拒绝发布。

补数报告在 `reports/data_repair/daily_price_status.json`，其中记录原始指纹、备份位置、覆盖数量和范围。随后通过 `scripts/update_daily_market_data.py --force-rebuild` 更新最近完整交易日并重建因子、特征、标签与模型产物。
