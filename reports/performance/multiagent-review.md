## 已修复

| 问题 | 修复 | 验证 |
| --- | --- | --- |
| 选择预测模型后，浏览器后退/前进只改变 URL，不改变组件的模型状态；新的 SSR 数据还可能与旧选择器不一致 | 以 URL 查询参数作为模型来源，并给 SSR 快照绑定对应请求 URL；其他模型的旧快照不能覆盖当前数据 | 运行时测试覆盖不匹配及迟到的 SSR 快照、刷新、请求取消和切回原模型；浏览器检查后退/前进 |
| 数值筛选用 Number(null)，把缺失因子当作 0 | 仅有限数值参与数值筛选，区间需要完整边界；未启用的筛选仍允许缺失值 | null、undefined、空字符串、布尔值、NaN、Infinity 与真实 0 的对照测试 |
| 每次查看未缓存股票，都读取整个 221,319 行日频表 | 在 Parquet 读取时按规范化股票代码过滤 | 完整个股响应除新增价格说明外与优化前一致；验证读取确实带 symbol 过滤条件 |
| 启动检查将 404 当作就绪，503 重试结束后也可能静默成功 | 仅接受成功状态码，重试耗尽必须抛错并带最后的失败原因 | 本机临时 HTTP 服务分别返回 200、404、503，验证进程退出状态 |
| 行情表和个股把后复权研究价格写成“最新价” | API 返回价格口径，页面显示“后复权收盘价”及对应说明；未提供口径时明确标为待确认 | 验证实际 hfq 数据、缺失行情和个股字段兼容 |

读取优化的单步对照：同一只股票 742 行，全表读取再过滤为 1.380 / 1.551 秒，Parquet 过滤读取为 0.168 / 0.122 秒；DataFrame 深度内存统计从 373,933,988 字节降为 1,254,112 字节。这是读取步骤，不能当成整个接口或页面的耗时。新进程内完整个股详情首只约 1.10 秒，第二只约 0.28 秒（共用同一天的因子截面）。

最终验证：本轮相关后端测试 20 项、前端运行时测试 9 项通过；生产构建、TypeScript 检查及 15 个路由校验通过。使用独立浏览器标签验证了模型切换、后退、前进，以及全景和个股页的价格说明，浏览器未捕获到 error 日志。网站已运行更新后的生产构建。页面验证截图：[全景页价格说明](multiagent-review-market.png)。

## 需要优先补齐的数据问题

1. **VWAP 偏离混用了复权与未复权价格，尚未修复数值。** `factors/offline/polars_factor_engine.py` 使用后复权 close 除以 amount/volume。2026-10-16 平安银行后复权 close 为 1468.123212，原始成交金额/股数为 11.526718，算出的偏离为 126.366975，即约 12,637%。最新有成交量的 299 只股票中，285 只的该 VWAP 不在复权 high/low 范围内。当前 adj_factor 全部为 1，不能用于恢复真实价格。需要采集未复权 OHLC 或可靠的复权因子，统一比较口径，再重算因子及受影响模型。不能用 VWAP 代替真实收盘价，也不能把当前预测视为已完成此项修复。
2. **历史 ST 标记并非真实历史状态。** `data/adapters/real_csi300_akshare.py` 将 st_flag 无条件设为 False；本地 221,319 行全部为 False。策略实验勾选排除 ST 时，主要依赖这些标记及已有名称信息，无法可靠排除历史 ST 阶段。需要补齐按日期生效的历史状态。现有回测假设已提示这类覆盖限制，本轮没有伪造状态或把全部未知股票删除。

## 后续可改进

- 从情绪模型排名进入个股详情后，目前详情仍固定展示 COGRASP，返回链接也不保留情绪模型选择。页面有模型名称，但完整的跨页模型上下文尚未打通。
- 生产启动目前每次启动缺失的前端服务都重新构建。服务器可以把构建与启动分开；若本地加入构建复用，应同时检查源码、依赖、环境变量和内部 API 地址，避免启动旧产物。
- 300 行、多个因子列的条件表仍一次渲染全部单元格。后续若样本扩大到全市场，应加入分页或虚拟列表；当前先保留全部 300 只的筛选语义。

价格与 ST 缺口属于研究数据正确性问题，优先级高于进一步压缩首屏或清理体积。
