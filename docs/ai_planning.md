# 自然语言看板与策略实验

两个入口分别在 `/visualization` 和 `/strategy-lab` 页面上方，复用 `/account` 个人设置中的服务商、模型和 API Key。密钥只保存在当前浏览器标签页的内存中，不随看板或实验记录保存。

## 使用方式

- 看板：输入“对比平安银行和招商银行近三个月的价格与成交量，分别用折线图和柱状图”，生成配置草案，查看股票、时间和图表后点击“应用到看板”。原有图表编辑、排序、布局保存及导出功能继续可用。
- 策略：输入“比较近半年的动量和低波动策略，观察 20 日，每 5 个交易日调仓，持仓 10 只”，生成方案后选择“填入参数，继续编辑”或“应用并运行比较”。收益、回撤、换手率、成本与回放均由原有回测引擎计算。
- 修改当前配置、切换模型、清除密钥或离开页面后，旧的生成响应不会覆盖新配置。修改需求也会清除旧草案。

## 支持范围

看板支持 1–4 只本地股票、1–8 张折线/柱状/面积/散点图、最多 12 个指标和五年日频区间。生成器只选择服务器股票与指标目录中的项目。

策略使用动量、反转、低波动、均线趋势四种规则，分别独立比较。支持共同观察期、持仓数量、交易日调仓间隔、初始资金、手续费、滑点，以及 ST、十日涨幅超过 100%、十日内四次异动排除开关。它不生成自定义 Python，不执行交易，也不把多个独立策略冒充为组合条件策略。指定个股/行业、止盈止损、自定义因子阈值等未实现要求会要求用户调整描述。

“最近”以本地最新行情日为截止。服务端验证日期范围、策略观察期、交易日数量、参数边界、未知股票/指标和重复配置；失败时不应用部分结果。多个策略的历史比较不等于样本外验证。

## 接口和验证

`POST /api/assistant/plan` 接收 `provider`、`model`、`task`、`prompt` 和 `current`，密钥仅通过 `X-AI-API-Key` 请求头传递。输出包含 `status`（`ready` 或 `needs_changes`）、`summary`、`notes`、`unsupported` 和 `config`。不支持的要求不会返回可应用配置。

规划与聊天共享固定服务商目录、来源校验和并发限额；请求/响应不缓存。模型原始错误体不返回浏览器。应用看板后调用现有 `/api/visualization/series`，执行策略使用 `/api/strategy-lab/run`。

测试使用模拟上游模型响应，覆盖密钥传输、错误处理、参数校验、草案预览、取消和晚到响应、看板应用保存，以及正确参数进入真实回测引擎。真实数据联调记录在 `reports/runtime/ai_planner_acceptance.json`；未调用付费模型。
