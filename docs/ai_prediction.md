# API 大模型因子概率预测

在「股票预测选股」选择「API 大模型 · 因子概率估计」，或从条件选股每行的「AI 概率」进入。复用「个人设置」的供应商、模型名称和 API Key；Key 仅保留在当前标签页内存。选择一只股票、3–10 个因子、未来 1/5/10/20 个交易日及震荡范围后，手动生成。

上涨指预测周期末收盘价相对数据截止日收盘价的累计收益大于阈值；下跌小于负阈值；震荡包含两侧边界。默认 ±1%，可选 ±0.1% 至 ±5%。采用数据标示的研究价格口径，不扣除指数涨幅。结果是 API 模型未校准的主观概率，不是本地回归模型输出转换的概率，也不是已验证胜率。尚无概率回测或在线评分功能。

## 数据与输出

- `POST /api/assistant/predict` 接收 `provider`、`model`、`symbol`、`horizon_days`、`neutral_band_pct`、`factors`。Key 只放在 `X-AI-API-Key` 请求头。
- 服务端读取本地股票池和因子目录，提供最近 30 个交易日收盘价与成交量、所选因子最新值和最近 5 次观测。数据截止日不等于当前日期；页面与结果均展示实际日期。
- 最新日必须有有效行情与成交量，最近 60 日至少 30 个有效收盘价，最新日至少三个所选因子有值。缺失保持 null，不以前值填充。元数据与序列各自检查读取前后的版本；更新期间不返回混合快照。因子文件带有可用时间时，仅纳入 `available_time <= prediction_time` 的观测，时间缺失或晚到均为空。
- 历史参考使用同一周期/阈值，最多最近 252 个结束日的重叠区间。窗口内缺失即跳过；这些区间不独立，频率不是模型的校准概率或准确率。
- 校验所有概率有限且位于 [0,1]，合计 1（容差 1e-6）；证据只能引用有当前值的所选因子。错误返回 502，不做归一化修补。模型可以拒绝估计并返回三个 null。
- 单次只预测一只股票；不自动调用、不批量调用。更改输入或凭据即取消前端等待、丢弃旧结果；服务器检测客户端断开后取消上游等待并释放并发名额。停止连接不能保证供应商退还已产生的费用。
- 进入个人设置再返回时保留预测模式与股票；在预测页切换股票也会停止侧边助手的旧分析。
- 预测快照导出 JSON，含输入、价格口径、数据版本、快照哈希、生成时间、因子依据和概率，不含 API Key；页面不自动保存预测。
- 与聊天/方案生成共用固定供应商目录和四个并发槽，限制返回体大小、时限，隐藏供应商错误原文。服务器运营者可继续通过既有环境变量配置兼容服务。

## 验证

`tests/test_ai_prediction.py` 覆盖输入、数据不足、缺失因子、阈值边界、概率校验、证据一致性、接口鉴权、上游错误及并发槽回收；`frontend/tests/ai-prediction-runtime.test.tsx` 覆盖显式调用、凭据传递、结果/空值显示、迟到响应取消和无密钥快照导出。测试使用模拟模型供应商，不能证明真实模型预测能力。
