# 策略实验与历史回溯

从主导航「策略实验」或 `/strategy-lab` 进入。选择历史区间、策略、观察期、持仓数量、调仓间隔、初始资金及单边成本后，点击「运行并比较」。

- 支持动量、反转、低波动、均线趋势四种规则策略，可以同时比较；等权基准使用同一日期、基础过滤、调仓周期与交易成本。
- 可剔除 ST、十日涨幅超过 100%、十日内至少四次异动。两个异常因子复用当前定义，未知值排除。勾选「剔除 ST」时，只允许信号日明确为非 ST 的股票入选；整列缺失、单日缺失或无效状态也会排除，不能当作非 ST。取消勾选才跳过这项过滤。
- 查看整个区间的累计收益、年化收益、最大回撤、夏普、超额收益、正收益日占比、双边换手和成本。
- 点击曲线、拖动滑块或播放逐日回放，检查持仓、现金、成交与未成交记录。
- 浏览器保存最近 8 次参数与结果摘要。恢复参数后需重新运行；重跑使用当前本地数据。导出完整 JSON 可保存原参数、数据指纹、引擎版本、指标、每日曲线、持仓和订单；CSV 用于指标对比。

## 计算口径

使用 `data/real/csi300_daily/part-000.parquet`，所有信号只使用执行日前一交易日及更早行情。下一交易日开盘按等权目标调仓，先卖后买，成本不足时按现金比例缩小买单；每个持仓日按收盘价估值。停牌或缺失有效开收盘价、成交量的股票不能交易，无法卖出的原持仓保留。缺失收盘价沿用最近有效收盘估值。订单只在调仓日尝试，当日未成交不自动延期。

费用 = 成交金额 ×（单边手续费基点 + 单边滑点基点）÷ 10000。两个方向分别扣费。期末资产包含按收盘估值的未平仓头寸，不加假设的清仓费用。允许按复权价计算比例持仓，未模拟整手、最低佣金、独立印花税、涨跌停排队和市场冲击。买卖可用标记来自本地行情源。

收益和回撤都包含首日交易成本；最高资产初始值为起始资金。年化使用 252 个交易日，夏普使用日收益样本标准差、无风险收益率设为零。超额收益是策略累计收益与等权基准累计收益的百分点差。正收益日占比含空仓日。日均双边换手为每日买卖金额之和除以开盘前组合资产后取均值。

当前成员的历史回溯存在幸存者偏差，历史 ST 等状态受来源限制；参数是在同一历史区间比较，不能视作独立样本外评估。现有模型的最新预测未用于历史实验，避免用当前模型输出替代历史时点预测。

## 接口与边界

- `GET /api/strategy-lab`：数据范围、可选策略、默认区间与计算口径。
- `POST /api/strategy-lab/run`：提交参数，返回完整实验。无服务器持久化副作用，沿用公开研究数据接口访问范围。

两个接口均返回 `st_coverage`：明确 ST、明确非 ST、未知状态的记录数及覆盖率。元数据统计全部本地历史行（`available_history_rows`）；实验结果统计各调仓信号日的股票池（`rebalance_signal_stock_days`），包括该股票当天缺失的行情记录。实验结果的 `exclude_unknown` 表示本次是否排除未知状态。这些数量描述 ST 数据覆盖，不代表最终持仓数量，因为还会应用观察期、价格和其他筛选条件。
- 单次最多 4 种策略、800 个交易日、50 只目标持仓；最多两个实验同时计算。无法卖出的旧持仓可能使实际持仓数暂时超过目标数。
- 参数错误返回 422、缺少行情返回 503、并发容量满返回 429。无网络行情抓取和模型重新训练。

验证入口：`python -m pytest tests/test_strategy_lab.py -q`。
