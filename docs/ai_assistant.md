# 页面研究助手

所有公开研究页右下角都有“AI 助手”，点击展开侧边聊天面板。模型服务、模型名称和 API Key 集中放在导航栏的“个人设置”（`/account`），聊天面板不再放配置表单。

界面采用常见聊天窗口布局：顶部标题、“＋ 新建对话”和关闭按钮，下方是可横向滚动的对话标签，中间消息列表，底部输入框与发送／停止按钮。点击“新建对话”创建独立标签，不清除已有对话。标签按首条问题自动命名，保留各自的消息、草稿和回复状态；切换标签时，原对话可以继续生成。关闭标签会中止该标签的请求并移除内容；关闭最后一个标签后自动保留一个空对话。标签支持方向键、Home／End 切换和 Delete 关闭。

消息输入支持 Enter 发送、Shift + Enter 换行和中文输入法，回复期间可以继续编辑下一条草稿；上滑阅读历史消息时不强制滚动到底部。

拖动助手左上角的斜线手柄可调整宽高，尺寸限制在当前屏幕内，并单独保存在本机浏览器。选中手柄后可用方向键微调，Esc 取消当前拖动；双击手柄或按 Home 恢复默认尺寸。缩放不会清空聊天或重新发送分析请求。

进入“个人设置 → AI 助手设置”，选择服务商并填写模型名称和 API Key，点击“应用设置”，再点“返回研究页”开始聊天。助手未配置时也会提供跳转入口。未登录可配置当前标签页的助手；已登录时个人设置同时展示当前账号和自选入口。

## 全局提示词与 Skill 技能池

“个人设置 → 提示词与技能”提供 `CLAUDE.md` 风格的全局提示词编辑区，可直接编写、启用／停用、导入 Markdown／文本文件并导出为 `CLAUDE.md`。保存后，每次聊天请求都会带入已启用的前缀。这里是网站的提示词设置，不会自动读取服务器或项目目录中的同名文件。

技能池默认提供因子解读、量价分析、策略复盘和反证检查。可新建、编辑、停用、删除技能，也可导入 `SKILL.md`；导入文本保留原文，并提取简单的 name／description 元数据用于展示。编辑与导入不会立即生效，点击“保存提示词与技能”后才会应用。未保存的修改可撤销。

聊天输入框上方的“技能”菜单用于选择技能，每段对话独立记住选择，单次最多 3 个；用户消息会标记本次使用的技能名称。只发送所选且已启用的技能，移除或停用的技能不再随新请求发送。设置变化对下一次发送生效，已经进行的回复仍使用发送时的配置。

全局提示词最多 8000 字符，单个技能指令最多 6000 字符，技能池最多 20 项；单次前缀与技能指令合计最多 20000 字符。导入文件最多 64 KB，仍需符合对应字符限制。前后端均验证边界，后端拒绝重复技能和非文本配置。

这些都是文本技能，供模型组织分析步骤，不执行脚本、不自动打开引用文件或链接，也不增加工具权限。它们作为用户研究偏好放在历史对话与当前问题之前，保留系统原有的数据来源、日期、复权口径等约束。目前只作用于聊天助手，不改变结构化策略／看板生成或 API 概率预测接口。

提示词与技能以独立的白名单配置保存在当前浏览器 localStorage，刷新后恢复，不随账号同步；API Key 和聊天记录仍不持久化。浏览器禁止保存时会提示，并仅在本次浏览中应用。编辑、导入和保存都不会触发模型调用。

## 使用与上下文

- 个股页自动选择当前股票，提供最近 30 根日线、最新未复权与复权价格、当前因子值及模型预测；聊天面板不再单独展示股票选择表单。
- 数据可视化带入当前股票、因子与区间；条件选股带入当前过滤条件、选中因子和最多 8 只结果样本，股票数值由后端重新读取。
- 股票全景带入涨跌分布和当前过滤结果的最多 10 只样本。不会把样本称作全部股票。
- 预测页跟随当前 COGRASP / 情绪融合模型选择。
- 实验页提供已运行结果的收益、回撤、成本、参数、数据指纹及当前回放点摘要。修改但尚未重跑的参数会单独标明。
- 每次回复附带可展开的数据来源与日期。数据只来自本站，不联网搜索、不下单。自选页不会自动把私人自选列表发送给模型。

聊天支持逐段显示、停止生成、多对话标签、错误后重试。对话按页面、个股代码与预测模型分别在内存中保留，避免不同研究对象共用历史；返回对应页面时恢复原来的标签、消息与草稿。切换页面或研究对象时停止原页面的未完成请求，密钥继续保留在内存。收起面板不会清空对话；刷新页面后会清空所有对话。个人设置里的修改在点击“应用设置”后生效；切换服务商会清空草稿中的原密钥，需要填写对应服务商的 Key。应用新设置、清除配置或账号状态变化时停止所有标签中的请求并清除所有对话。设置页本身不提供行情分析聊天。

## 密钥和数据

密钥只存在于当前标签页的共享组件内存和本次后端转发请求，不写入 localStorage、sessionStorage、cookie、数据库或日志，也不跨设备同步。通过站内导航在个人设置和研究页之间切换时保留；刷新、退出或切换账号后重新填写。本站也不保存聊天内容。API Key 放在请求头，不放在 URL 或模型消息里。生产环境应使用 HTTPS，代理和监控系统不要记录请求头或正文。

发送后，问题、最近的完整对话、所选行情/因子及实验摘要会由本站转发至所选服务商，费用由用户自己的 API 账户承担。服务商的数据处理政策仍适用。“本站不保存”不代表服务商不保存。

默认支持 DeepSeek、OpenAI、通义千问北京地域；模型名称可以修改。服务器可通过 `AI_ASSISTANT_BASE_URL` 和 `AI_ASSISTANT_MODEL` 增加一个受控的 OpenAI 兼容服务（HTTPS，base URL 不含 `/chat/completions`）。不接受来自浏览器的任意转发地址。服务商切换后应使用该地域/服务商对应的密钥。

后端每个进程最多并行 4 个分析请求，连接超时 10 秒，读取超时 25 秒，总生成时间限制 90 秒。上游重定向关闭；错误信息不回显上游响应正文。接口响应设置 `no-store`。反向代理需支持流式响应，建议读取超时不少于 100 秒并关闭此路径的响应缓冲。

## 验证

```powershell
.venv\Scripts\python.exe -m pytest tests/test_ai_assistant.py -q
npm --prefix frontend run test:runtime
npm --prefix frontend run build
```

测试使用模拟模型服务，不消耗真实 Key 额度。真实模型的账户可用性、余额和网络连通性需在填写用户自己的 Key 后验证。没有测试密钥时，不把模拟回答描述为真实模型结果。

接口依据：[OpenAI Chat Completions](https://developers.openai.com/api/reference/resources/chat/subresources/completions/methods/create)、[DeepSeek Chat Completions](https://api-docs.deepseek.com/api/create-chat-completion/)、[阿里云百炼兼容接口](https://www.alibabacloud.com/help/en/model-studio/model-calling-in-sub-workspace)。
